# 🚀 БЫСТРОЕ РАЗВЕРТЫВАНИЕ / QUICK DEPLOY

## Запустите СЕЙЧАС (не нужно сливать PR):

```bash
./deploy.sh
```

ИЛИ:

```bash
npm run deploy
```

## После выполнения команды:

1. Перейдите в Settings → Pages: https://github.com/Sazonow/Voltage-Analyzer-Pro/settings/pages
2. Выберите:
   - **Source**: Deploy from a branch
   - **Branch**: gh-pages
   - **Folder**: / (root)
3. Нажмите Save

## Готово! 🎉

Сайт будет доступен через 1-2 минуты:
**https://sazonow.github.io/Voltage-Analyzer-Pro/**
