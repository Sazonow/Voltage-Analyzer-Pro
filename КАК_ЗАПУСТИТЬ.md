# Как запустить сайт на GitHub Pages

## 🚀 БЫСТРЫЙ СПОСОБ (работает сейчас!)

Запустите в терминале:
```bash
./deploy.sh
```

ИЛИ:
```bash
npm run deploy
```

Затем в Settings → Pages выберите:
- Source: "Deploy from a branch"  
- Branch: **gh-pages** → **/ (root)**
- Ссылка: https://github.com/Sazonow/Voltage-Analyzer-Pro/settings/pages

**Готово!** Сайт будет доступен через 1-2 минуты: https://sazonow.github.io/Voltage-Analyzer-Pro/

---

## Альтернативный способ (через PR и GitHub Actions)

### 1️⃣ Слейте этот PR
Нажмите зеленую кнопку **"Merge pull request"** на странице PR

### 2️⃣ Включите GitHub Pages
Перейдите: Settings → Pages → Source → Выберите **"GitHub Actions"**
Прямая ссылка: https://github.com/Sazonow/Voltage-Analyzer-Pro/settings/pages

### 3️⃣ Подождите 2-3 минуты
Workflow автоматически запустится и развернет сайт

## ✅ Готово!
Ваш сайт: https://sazonow.github.io/Voltage-Analyzer-Pro/
