# 🚀 3 СПОСОБА РАЗВЕРНУТЬ САЙТ

## ⭐ СПОСОБ 1: САМЫЙ ПРОСТОЙ (рекомендуется)

### 1. Слейте PR
Нажмите кнопку на этой странице: **"Merge pull request"** → **"Confirm merge"**

### 2. Настройте Pages
- Откройте: https://github.com/Sazonow/Voltage-Analyzer-Pro/settings/pages
- **Source**: выберите **"GitHub Actions"**
- Сохраните

### 3. Готово! ✅
Подождите 2-3 минуты. Сайт будет здесь: https://sazonow.github.io/Voltage-Analyzer-Pro/

---

## 🔧 СПОСОБ 2: Через командную строку

### 1. Откройте терминал на вашем компьютере
- **Windows**: Нажмите `Win+R`, введите `cmd`
- **Mac**: Нажмите `Cmd+Space`, введите "Terminal"
- **Linux**: Нажмите `Ctrl+Alt+T`

### 2. Выполните команды:
```bash
git clone https://github.com/Sazonow/Voltage-Analyzer-Pro.git
cd Voltage-Analyzer-Pro
git checkout copilot/setup-project-with-github-pages
npm install
npm run deploy
```

### 3. Настройте Pages
- Откройте: https://github.com/Sazonow/Voltage-Analyzer-Pro/settings/pages
- **Source**: "Deploy from a branch"
- **Branch**: выберите **gh-pages** → **/ (root)**
- Сохраните

---

## ☁️ СПОСОБ 3: Через GitHub Codespaces (онлайн, без установки)

### 1. Откройте Codespaces
- Перейдите: https://github.com/Sazonow/Voltage-Analyzer-Pro
- Нажмите: **<> Code** (зеленая кнопка)
- Вкладка: **Codespaces**
- Нажмите: **"Create codespace on copilot/setup-project-with-github-pages"**

### 2. В открывшемся редакторе
Внизу есть терминал. Выполните:
```bash
npm install
npm run deploy
```

### 3. Настройте Pages
- Откройте в новой вкладке: https://github.com/Sazonow/Voltage-Analyzer-Pro/settings/pages
- **Source**: "Deploy from a branch"
- **Branch**: выберите **gh-pages** → **/ (root)**
- Сохраните

---

## ❓ Какой способ выбрать?

- **Не знаете что такое терминал?** → Используйте **СПОСОБ 1** (самый простой)
- **Есть Git на компьютере?** → **СПОСОБ 2** (быстрее всего)
- **Ничего не установлено?** → **СПОСОБ 3** (работает в браузере)
